# Service Package - agent-orchestration-benchmark

This package defines the most practical service shape for this repository. It is public-safe: no price promises, financial projections, or buyer-specific contract assumptions are published here.

## Buyer and Wedge

- **Service lane:** Agent framework selection
- **Primary buyer:** AI platform leaders comparing orchestration frameworks
- **Front-door offer:** Framework selection audit
- **Service outcome:** Make framework choice evidence-based through reproducible benchmark fixtures and tradeoff notes.

## Build and Polish Priorities

- Clarify benchmark fixture scope and supported frameworks
- Add decision matrix language for buyer review
- Separate public benchmark proof from private provider runs

## Buyer-Ready Deliverables

- Benchmark packet
- Tradeoff matrix
- Selection workshop

## Activation Path

1. Use the public demo, README, screenshots, and tests to establish proof.
2. Confirm the buyer workflow, data boundary, owner, and acceptance criteria.
3. Build only the smallest workflow needed to prove the service outcome.
4. Add cloud resources, accounts, storage, or paid integrations only after the workflow boundary is approved.

## Margin and Risk Controls

- Keep benchmarks reusable and run private provider tests only after scope is approved.
- Keep the first service scope narrow, repeatable, and evidence-led.
- Keep private financial planning outside the public repository.
- Keep logs, analytics, and reports free of private payloads unless explicit approval exists.

## Portfolio Signal

The portfolio should present this repository as **Framework selection audit** under the **Agent framework selection** lane, with proof links routed to the live demo or repository evidence.
